# Atharva Deshmukh — Portfolio

A responsive personal portfolio for presenting Atharva's background, skills, selected projects, and contact information. The site features an interactive technology section and animated software-development architecture visuals.

## Built with

- React
- Vite
- Three.js
- GSAP
- Lenis
- Lucide React

## Run locally

Requires Node.js 18 or later.

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

Vite outputs the deployable site to `dist/`. Deploy the contents of that folder to a static web host.

## Project structure

- `src/main.jsx` — app entry point and primary portfolio sections
- `src/components/` — selected work, technology, and software-development sections
- `src/*.css` and component CSS files — site and section styles
- `public/images/` — images served as static assets

## Before publishing

Review the project content, contact details, social links, and resume link in `src/` to ensure they are current and point to the intended destinations.
